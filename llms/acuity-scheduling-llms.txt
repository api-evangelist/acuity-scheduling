## API Reference
- [Quick Start](https://developers.acuityscheduling.com/reference/quick-start.md)
- [/appointments](https://developers.acuityscheduling.com/reference/get-appointments.md): Get a list of appointments currently scheduled for the authenticated user.
- [/appointments](https://developers.acuityscheduling.com/reference/post-appointments.md): Create an appointment.
- [/appointments/:id](https://developers.acuityscheduling.com/reference/put-appointments-id.md): Update an appointment details from a white-list of updatable attributes.
- [/appointments/:id/payments](https://developers.acuityscheduling.com/reference/get-appointments-id-payments.md): Retrieve a list of payment transactions for a particular appointment.
- [/meta](https://developers.acuityscheduling.com/reference/meta.md): Metadata for Acuity services.
